Zo kom je binnen

Vraag met je e-mailadres een code aan. Die code is tien minuten geldig en werkt één keer. Daarna opent de tool zich en kun je rekenen.

De code kan in je spambox of in de map ongewenste e-mail belanden. Kijk daar als je hem niet meteen ziet.

Je e-mailadres gebruiken we alleen om die code te sturen en, als je dat wilt, om contact met je op te nemen.
