Rekentool

De rekentool opent in een beveiligde omgeving. Daar vraag je met je e-mailadres een eenmalige code aan, en die code opent de tool.

De code kan in je spambox of in de map ongewenste e-mail belanden. Kijk daar als je hem niet meteen ziet.

Rekentool openen

Je e-mailadres gebruiken we alleen om die code te sturen en, als je dat wilt, om contact met je op te nemen. De code is 10 minuten geldig en werkt één keer.
